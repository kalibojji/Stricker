Sticker express

Colle un lien X, Bluesky ou une image : récupère, détoure, enregistre.

Image → autocollant :
  1. Ouvre Photos, appui long sur l'image.
  2. Touche Ajouter un autocollant : il apparaît dans le clavier emoji (WhatsApp, iMessage…).
Vidéo → autocollant animé :
  1. Ouvre l'app gratuite intoLive, choisis la vidéo enregistrée, touche Save Live Photo.
  2. Dans Photos, appui long sur cette Live Photo → Ajouter un autocollant : il bouge dans le clavier.
Astuce : Partager → Sur l'écran d'accueil pour l'avoir comme une appli.
